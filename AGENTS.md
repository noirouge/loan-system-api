# Instrucciones para agentes

Este proyecto se documenta en un vault de Obsidian dentro de `docs/`.

**Antes de hacer cualquier cosa, lee `docs/00 Inicio.md`** y sigue sus reglas y su orden de lectura. Ahí están el modelo de negocio, las convenciones del código, el plan, las tareas, las decisiones y las preguntas abiertas.

Al terminar un cambio, actualiza el vault como indica esa nota.
